Carrefour Reference Data Management Tool

A centralized solution designed to manage, update, and consult Carrefour’s reference data repositories. It ensures consistency, integrity, and reliability of the information used across the company's various entities. Built on a microservices architecture, it uses a Java Spring Boot back end and an Angular front end to offer an intuitive user interface. The application includes secured APIs, change history tracking, and a data validation mechanism to guarantee the quality of reference data.
